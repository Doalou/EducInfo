Outil de diagnostic et réinitialisation

Cet outil vous permet de diagnostiquer et de résoudre les problèmes d'authentification lorsque les méthodes standard ne fonctionnent plus.

Un code de sécurité à usage unique est nécessaire pour continuer. Ce code peut être généré par l'administrateur système via la commande CLI :

flask admin generate-emergency-code

Cette mesure de sécurité garantit que seul un utilisateur autorisé puisse accéder à cet outil sensible.

Les codes sont à usage unique et expirent après utilisation.
